MCP server FAQs

Which AI tools work with the LinearB MCP server?

Claude, Claude Code, ChatGPT, Codex, Cursor, VS Code, Windsurf, Zed, Cline and any other client that supports MCP. Each person connects with their own LinearB account through OAuth. In Claude, custom connectors need a paid plan. Connect the MCP server →

Does the LinearB MCP server connect to Slack, Salesforce or Notion itself?

Your AI tool does the combining. Add the MCP servers or connectors for your other tools to the same client, and one prompt can use LinearB data alongside theirs.

Can we use it alongside the MCP servers we already have?

Yes. The LinearB MCP server runs next to any other MCP server in your client, such as Claude Desktop or ChatGPT.

What data can the MCP server reach?

Metrics and benchmarks, pull requests, branches, releases, incidents, services, teams, contributors, issues, and project management entities such as epics and initiatives. It reads the git, project management and incident data you’ve connected to LinearB. Every git provider and project management tool LinearB supports works with it, including GitHub, GitLab, Bitbucket, Azure DevOps and Jira.

Does role-based access apply to the MCP server?

Yes, when people connect through OAuth. The MCP server returns only the data each person’s LinearB role and team scope allow. For clients that don’t support OAuth, a Company Admin can use an organization-scoped API key instead.

How do I get the same report every time?

Save the prompt as a scheduled task or a reusable page in your AI tool, and keep the teams and timeframe explicit. The LinearB MCP server comes with ready-made prompts for release, urgent PR, lead time and merge rate reports, and the LinearB prompt library has more.

How accurate are the answers?

The numbers come from LinearB, but your AI tool writes the answer, so results can be incomplete in edge cases. Ask for one metric, team and timeframe at a time, and check figures in your LinearB dashboards before you make a decision on them.
